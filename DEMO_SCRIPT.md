# Cashu Nexus — reviewer walkthrough (about 90 seconds)

1. **Overview:** Show the demo balance and recent activity. Point out the persistent “Interactive demo / No real funds” labels.
2. **Send:** Open Send ecash, enter a harmless placeholder beginning with `cashu` (for example `cashuA-demo-placeholder`), and review the demo state. Explain that no token is decoded, sent, or spent. Add a sample activity item to show the local-only interaction.
3. **Receive:** Choose an amount and create a demo request. Highlight the warning that the string is not an invoice and cannot receive a payment.
4. **Activity:** Search/filter the local history and export a CSV.
5. **Mint directory:** Add a URL bookmark and remove it. Explain that Nexus does not connect to or verify the mint.
6. **Privacy & safety:** Highlight the short explanations of blind signatures, mint trust, bearer-token handling and recovery.
7. **Settings:** Reset the demo to its original sample state.

**Closing message:** Nexus focuses on trust clarity and approachable UX. A production wallet would require a maintained Cashu SDK, protocol-correct mint operations, secure key/proof handling, recovery design, test-mint coverage and an independent security review.
